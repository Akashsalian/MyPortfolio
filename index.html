Flagship Project

FocusGuard — Real-Time AI Screen-Safety & Wellness App

A real-time computer vision app that watches for unsafe screen distance and blink rate, then nudges the user to take a break — backed by a model I trained myself, not a wrapped third-party API.

GitHub ↗
Problem

Long screen sessions quietly damage posture and eye health, and most "wellness" tools either need a wearable or just run a dumb timer with no idea what's actually happening in front of the camera.

Solution

A webcam-based pipeline that measures real screen distance and blink frequency in real time, using a Random Forest model trained on a self-collected dataset rather than a generic pretrained API.

Architecture
  • MediaPipe Face Mesh for landmark extraction from the live webcam feed
  • Custom Random Forest classifier — 240+ self-collected images, 95% cross-validation accuracy
  • FastAPI + WebSocket backend streaming live camera data for low-latency inference
  • Blink detection via Eye Aspect Ratio (EAR) math, driving break-reminder logic
  • Offline RAG assistant — ChromaDB + Ollama (Llama 3.2) — giving session-based recommendations with no cloud dependency
Challenges & Learnings

Collecting and labeling my own image dataset was the hard part — getting a model that generalized past my own face and lighting meant iterating on the feature set, not just the classifier. Running the RAG assistant fully offline also forced me to get comfortable with local embedding storage and model quantization trade-offs.
